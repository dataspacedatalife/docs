# OneHealth DataSpace HPC Cluster – Terms of Use

## Initial Resources Allocation

To promote responsible use of the cluster and prevent inefficient workloads from consuming excessive computational resources, **all newly authorized users are initially assigned a SLURM limitation that allows only one concurrent job**.

This temporary restriction is intended to allow users to:

- Verify that the execution environment is correctly configured.
- Test software installations and dependencies.
- Validate job submission scripts.
- Optimize resource requests (CPUs, memory, GPUs, wall time, etc.).
- Ensure that production workloads make efficient use of the available infrastructure.

Once the initial testing phase has been successfully completed and the user's workloads have been optimized, **the one-job limitation will be lifted**, allowing normal access to the cluster resources.

## User Responsibilities

By using the OHDS HPC Cluster, users agree to:

- Use computational resources responsibly and efficiently.
- Request only the resources required by each job.
- Test and optimize workflows before submitting large-scale production workloads.
- Report any technical issues that may affect the operation of the cluster.
